# بوت أفياتور — جامع النتائج وبيانات Provably Fair

هذه النسخة تركز على **اللعبة الحقيقية المفتوحة في Chrome**، وليس على محاكاة Workspace.

## ما الذي تم إصلاحه

- التقاط `OnStage` / `OnBetting` / `OnStart` / `OnCrash` وغيرها من WebSocket.
- تسجيل WebSocket frames كاملة في `game_network.jsonl`.
- تسجيل طلبات واستجابات HTTP وJSON المناسبة، بما فيها body، مع إخفاء الحقول الحساسة.
- مراقبة جميع إطارات/iframes الصفحة.
- فحص `innerText` وHTML والـ attributes والـ meta والـ script والـ localStorage/sessionStorage.
- تحليل JSON وبذور Provably-Fair من الحقول المسماة فقط قدر الإمكان، بدل اعتبار أي سلسلة hex بذرة تلقائيًا.
- إضافة `diagnostics.jsonl` لتحديد مصدر بيانات العدل فعليًا.
- **إصلاح ربط البذور المتأخرة:** إذا ظهرت `Server Seed` بعد `OnCrash`، تُلحق بالجولة التي انتهت بدل ضياعها في الجولة التالية.
- إعادة التحقق من الجولة عند وصول أي بيانات Seed جديدة.
- عند اكتمال بيانات العدل بعد إرسال تنبيه انتهاء الجولة، يرسل البوت تحديثًا واحدًا إلى Telegram بدل إبقاء الرسالة القديمة فقط.

## ملاحظة مهمة

إذا لم تظهر `Server Seed` أو `Client Seed` أو `Seed Hash` في `HTTP/WebSocket/DOM/storage`، فالبرنامج **لن يخترعها**. ستسجل الحالة كمصدر غير موجود، ويمكن استخدام `diagnostics.jsonl` لمعرفة أين يجب البحث عند فتح لوحة Provably Fair في الموقع.

الـ Predictor لم يتم تغييره.

## التشغيل

1. أنشئ Bot Token جديدًا من BotFather لأن التوكن الموجود في النسخة السابقة كان مكشوفًا.
2. ضع التوكن الجديد في `config.json` عند `bot_token`.
3. شغّل `run_bot.bat` أو:

```bat
pip install -r requirements.txt
python bot.py
```

4. اترك Chrome مفتوحًا على صفحة اللعبة وسجّل الدخول يدويًا إن لزم.
5. عند الحاجة إلى اختبار بيانات Provably-Fair، افتح نافذة/لوحة Provably Fair في اللعبة واتركها ظاهرية لفترة قصيرة؛ الجامع يلتقط DOM والطلبات الجديدة تلقائيًا.

## الملفات

- `history.json` — سجل المضاعفات.
- `rounds.json` — الجولة مع بيانات العدل ومعلومات التحقق.
- `live_state.json` — حالة الجولة الحالية.
- `seeds.jsonl` — سجل عمليات التقاط/إثراء البذور.
- `game_network.jsonl` — WebSocket + HTTP المراقَب.
- `diagnostics.jsonl` — سجل تشخيصي للمصادر المرشحة.

## Workspace / Grok Aviator

المجلد `Grok Aviator` هو مشروع Web/PWA منفصل للواجهة/المعاينة، وليس مصدر نتائج اللعبة الحقيقية. لا يعتمد عليه الجامع.


## مهم: عدم وصول رسائل Telegram

البوت لا يستطيع إرسال تنبيه إلى محادثة لم تسجّل نفسها. بعد تشغيل `run_bot.bat` افتح البوت في Telegram وأرسل `/start` مرة واحدة، أو `/test` لاختبار الإرسال وتسجيل المحادثة.

ستظهر في نافذة التشغيل رسائل مثل:
`[TELEGRAM] subscribers=[...]`
ثم عند الإرسال:
`[TELEGRAM] sent -> <chat_id>`

إذا فشل Telegram، ستجد التفاصيل في `telegram_errors.log`. أخطاء الشبكة لا تحذف المشترك تلقائيًا؛ الإزالة تتم فقط عند خطأ حظر مؤكد.
